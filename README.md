# OptiWin
OptiWin: a point-and-click Windows 10/11 debloater. Removes built-in, Store and desktop apps, bloatware, OneDrive, Edge (keeps WebView2) and Python packages; disables services, startup, telemetry and Delivery Optimization; clears caches. Preview-first with restore points and roll-back. Powered by CyberX, SVPNPA.
